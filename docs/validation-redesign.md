# Проверка редизайна — 2026-10-21

Обновлённый интерфейс и отмена голосов проверены локально на синтетических данных. Production, DNS и VPS не менялись. Предыдущие инфраструктурные проверки остаются в [отчёте MVP](validation.md).

## Изменения

- Вместо hero/sidebar/footer — предложения, одна кнопка «Написать» и компактные фильтры. Подробности вынесены в navbar Popover «?». Форма имеет один заголовок и переключатель «Предложение / Ошибка».
- Новый [сгенерированный логотип с лампочкой](assets/feedback-bulb.md), локальный favicon и иконки проектов. Ссылки Campus и Unlikely UI открывают известный сайт/страницу пакета; неизвестный URL не выдуман.
- Реальный опубликованный PhysicalButton переключает голос. DELETE снимает только голос текущего signed-cookie посетителя; повторный POST возвращает его сразу. Inactive row сохраняется, квота не возвращается, cooldown для новых посетителей не удаляется. Миграция004 сохраняет существующие голоса активными.
- Выбранный/подсвеченный пункт Select заполняет фон до краёв меню; изменены только scoped стили приложения.
