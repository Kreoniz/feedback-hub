## Изменения и исправления

Тёмная тема включена по умолчанию; выбор пользователя сохраняется между страницами и после обновления. При запрете localStorage приложение продолжает работать, а после перезагрузки возвращается к тёмной теме.

[Независимый privacy review](review-release-privacy-r1.md) не обнаружил подтверждённых credentials или приватных обращений в проверенной истории. Его замечание о `web/.local` устранено рекурсивными Docker exclusions; релиз дополнительно собирается из чистого Git-export. Личные параметры убраны из текущих шаблонов. Исторические операционные идентификаторы и обычные Git author metadata остаются в приватной истории; аудит не является доказательством отсутствия произвольных скрытых данных.

Проверка образа от runtime UID обнаружила нечитаемые скопированные PNG после экспорта с umask077. До публикации добавлено явное чтение public assets в final stage и выполнена повторная сборка. Все восемь файлов образа совпадают с локальной сборкой и публичными HTTPS-ответами.

Проверка на реальном HTTPS выявила гонку сброса поиска до завершения debounce. Сброс теперь очищает и текущий ввод, и URL-фильтры на доске и в админке. Добавлена проверка админского сценария; browser assertion загрузки иконок ожидает фактического декодирования изображения вместо мгновенной проверки после открытия меню.

- Go vet, race и PostgreSQL integration, TypeScript, 31 frontend unit-тест и production build: PASS. После последнего изменения frontend повторены typecheck/unit/build и полный E2E; backend не менялся.
- Все 5 Firefox E2E на отдельном локальном API/тестовой БД: PASS — отправка, сохранение черновика при сетевой ошибке, модерация, приватность, идемпотентное голосование/отмена, дубликаты и спам, skeletons, иконки, тема и mobile admin.
- На production: 4 read-only Firefox-теста с axe, включая 320/390/1280px, клавиатуру, фильтры, exit-анимацию, тему и заблокированный storage: PASS. Admin layout использует перехваченные GET-fixtures, не приватные записи.
- Настоящий мобильный admin login, сохранение сессии после refresh, cookie Secure/HttpOnly/SameSite=Strict и logout: PASS. Credentials и inbox contents не записывались в браузерные артефакты.
- Перед открытием ingress синтетический production smoke проверил приватный bug, pending feature, одобрение, публичную проекцию, повторный голос и отмену, Origin/CSRF и отказ без авторизации. Две собственные записи и связанные тестовые данные удалены под write pause до публикации; opaque receipts сопоставлялись с записями только через авторизованный inbox.
- HTTPS, HSTS, CSP, no-store для HTML, 8 точных asset hashes, закрытые health/env/Git paths и admin API401: PASS. Все 10 ранее существовавших сайтов сохранили исходные HTTP-статусы.
- Фактический Caddy 2.11.4: конфигурация валидирована до одного reload; container ID и inode bind-mounted конфига сохранены. Proxy trust соответствует единственному проверенному peer. Прежние маршруты сохранены.
- Входные заголовки Caddy ограничены 32KB/10s. Body limit64KB и read/write10s/30s применяются только новому сайту. Синтетические upstream502 в live error logs подтвердили удаление URI, headers, обоих IP-полей и remote port; access logging для сайта не включён.
- Production backup восстановлен в новую одноразовую БД: 4 миграции, 0 исходных обращений/голосов. Временная БД удалена, live БД не заменялась. Начальный dump и отдельный архив новых runtime secrets скопированы в защищённое локальное хранилище; перед финальным обновлением сделан ещё один backup.

## Ограничения

GitHub Actions настроен, но [проверенный запуск](https://github.com/Kreoniz/feedback-hub/actions/runs/39599140018) не начал ни одного шага из-за billing/spending limit аккаунта. Эквивалентные проверки выполнены локально; автоматический production deploy не настраивался.

Автоматического расписания/offsite backup пока нет. Сохранённые recovery-копии требуют дальнейшего контроля хранения. Внешний L7 anti-DDoS не подключался; ограничения приложения не заменяют сетевую защиту. Safari и screen reader вручную не проверялись. При смене IP общего Caddy нужно сверить и обновить exact proxy trust по runbook.
